# Sound Processor

Консольное приложение на C++17 для обработки и генерации WAV-файлов. Позволяет менять амплитуду, нормализовать сигнал, вставлять паузы, менять длительность записи и создавать синусоидальные, AM- и FM-сигналы. Операции объединяются в цепочку и выполняются в порядке передачи аргументов.

## Возможности

- Чтение и запись несжатого WAV PCM: моно, 16 бит, 44 100 Гц.
- Изменение амплитуды с ограничением значений диапазоном `int16_t`.
- Нормализация до заданного пикового уровня.
- Вставка тишины в выбранную позицию записи.
- Изменение длительности линейной интерполяцией с изменением высоты звука.
- Фильтр `lowpass`, задуманный как сглаживание скользящим средним; особенности текущей реализации описаны ниже.
- Генерация синусоиды, амплитудно-модулированного и частотно-модулированного сигнала.

## Требования и сборка

- CMake **3.31 или новее**.
- Компилятор с поддержкой **C++17**. В коде используются `__attribute__((packed))` и `M_PI`, поэтому для сборки подходят GCC/Clang; совместимость с MSVC может потребовать правок.
- Git для клонирования репозитория.

Сторонние библиотеки не подключаются.

```bash
git clone https://github.com/8am-cd/sound_processor.git
cd sound_processor
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

В примерах ниже используется путь к исполняемому файлу для Unix-подобной среды и генератора CMake с одной конфигурацией:

```bash
./build/sound_processor
```

Запуск без аргументов выводит краткую справку по ключам `-i`, `-o`, `-f`. Отдельный ключ `--help` не реализован.

## Использование

```text
sound_processor [-i INPUT.wav] -o OUTPUT.wav [-f NAME PARAMS...]...
```

| Ключ | Назначение |
| --- | --- |
| `-i INPUT.wav` | Входной WAV-файл. Необязателен при генерации сигнала. |
| `-o OUTPUT.wav` | Выходной WAV-файл. Обязателен при запуске с аргументами. |
| `-f NAME PARAMS...` | Операция и её параметры. Ключ можно повторять. |

Числа с дробной частью указываются через точку. Пути с пробелами заключаются в кавычки.

Обработка выполняется по схеме:

```text
Входной WAV или пустой сигнал → операция 1 → операция 2 → … → выходной WAV
```

Без `-i` обработка начинается с пустого сигнала: для получения звука поставьте генератор первым в цепочке. Генератор полностью заменяет текущий сигнал, в том числе прочитанный из файла.

**Используйте разные пути для входа и выхода:** выходной файл открывается с перезаписью до чтения входного. Существующий выходной файл перезаписывается без подтверждения.

## Фильтры

| Синтаксис после `-f` | Параметры и действие |
| --- | --- |
| `ampl FACTOR` | `FACTOR >= 0`. Умножает отсчёты на коэффициент: `0.5` ослабляет сигнал вдвое, `2` усиливает вдвое, `0` даёт тишину. Значения за пределами диапазона от −32768 до 32767 обрезаются. |
| `normalize PEAK` | `0 <= PEAK <= 1`. Масштабирует сигнал до заданной доли от положительного максимума 32767. Например, `0.8` соответствует пику около 26213. Нулевой сигнал остаётся без изменений. |
| `silence UNIT START END` | `UNIT` — `sec` или `ms`; `0 <= START <= END`. Вставляет паузу длиной `END - START` в позицию `START`, сдвигая последующий звук вправо. Позиция `START` должна находиться в пределах исходной записи или на её конце. |
| `timestretch FACTOR` | `FACTOR > 0`. Новое число отсчётов — `round(N × FACTOR)`. Значение `0.5` сокращает длительность вдвое и повышает высоту звука; `2` задаёт удвоение длительности и снижение высоты. Для растяжения есть ограничение реализации, указанное ниже. |
| `lowpass WINDOW` | Положительный нечётный размер окна в отсчётах, например `5`. Предназначен для сглаживания; параметр не является частотой среза в герцах. Текущая реализация требует исправления. |

### Изменение амплитуды

```bash
./build/sound_processor -i tone.wav -o quiet.wav -f ampl 0.5
```

### Нормализация

```bash
./build/sound_processor -i tone.wav -o normalized.wav -f normalize 0.8
```

### Вставка паузы

```bash
./build/sound_processor -i tone.wav -o pause.wav -f silence sec 1 1.5
```

В позицию 1 секунда вставляется 0,5 секунды тишины. Исходный звук начиная с этой позиции сдвигается: запись длительностью 2 секунды станет длиться 2,5 секунды.

### Сокращение длительности

```bash
./build/sound_processor -i tone.wav -o fast.wav -f timestretch 0.5
```

Это изменение скорости воспроизведения посредством пересчёта отсчётов. Высота звука не сохраняется.

## Генераторы

Все генераторы создают монофонический сигнал с частотой дискретизации 44 100 Гц. Частоты задаются в **герцах**, длительность — в **миллисекундах**. Число отсчётов вычисляется как `duration × 44100 / 1000` с отбрасыванием дробной части.

| Синтаксис после `-f` | Параметры |
| --- | --- |
| `generator sin FREQUENCY DURATION` | Частота `FREQUENCY >= 0`, длительность `DURATION >= 0`. Синусоида с амплитудой 32767; уменьшить её можно следующим фильтром `ampl`. |
| `generator am AMPL CARRIER MODULATION DEPTH DURATION` | Амплитуда `AMPL` от 0 до 1; несущая `CARRIER >= 0`; частота модуляции `MODULATION >= 0`; глубина `DEPTH` от 0 до 1; длительность `DURATION >= 0`. |
| `generator fm AMPL CARRIER MODULATION DEVIATION DURATION` | Амплитуда `AMPL` от 0 до 1; несущая `CARRIER >= 0`; частота модуляции `MODULATION > 0`; девиация частоты `DEVIATION >= 0` в Гц; длительность `DURATION >= 0`. |

У AM-генератора огибающая равна `1 + DEPTH × sin(2π × MODULATION × t)`. При больших `AMPL` и `DEPTH` возможен клиппинг: итоговые отсчёты ограничиваются диапазоном `int16_t`.

### Синусоида 440 Гц на 2 секунды

```bash
./build/sound_processor -o tone.wav -f generator sin 440 2000
```

Этот файл можно использовать как входной для примеров фильтров выше.

### Амплитудная модуляция

Несущая 440 Гц, модуляция 5 Гц, глубина 0,8, длительность 2 секунды:

```bash
./build/sound_processor -o am.wav -f generator am 0.5 440 5 0.8 2000
```

### Частотная модуляция

Несущая 440 Гц, модуляция 5 Гц, девиация 50 Гц, длительность 2 секунды:

```bash
./build/sound_processor -o fm.wav -f generator fm 0.7 440 5 50 2000
```

### Цепочка операций

Создать синусоиду на 2 секунды, уменьшить амплитуду до 30% и вставить паузу на 250 мс в позицию 500 мс:

```bash
./build/sound_processor -o result.wav \
  -f generator sin 440 2000 \
  -f ampl 0.3 \
  -f silence ms 500 750
```

Итоговая длительность — 2,25 секунды. Перестановка операций может изменить результат.

## Формат WAV

Читатель рассчитан на несжатый **PCM, 1 канал, 16 бит, 44 100 Гц** и простую структуру файла: `RIFF/WAVE`, затем `fmt ` размером 16 байт, затем `data`. Поиск произвольно расположенных чанков не реализован, поэтому WAV с дополнительными метаданными или расширенным `fmt ` может быть отклонён даже при подходящих параметрах аудио.

MP3, FLAC, стерео, другие частоты дискретизации и разрядности не поддерживаются. Выходной файл всегда записывается в указанном PCM-формате. Весь сигнал загружается в оперативную память.

## Структура проекта

```text
sound_processor/
├── main.cpp                 # Точка входа и обработка исключений
├── CMakeLists.txt           # Сборка исполняемого файла
├── Application/             # Регистрация операций и запуск обработки
├── ArgsParser/              # Разбор ключей и параметров CLI
├── Cmd2PipelineConverter/   # Создание цепочки по описаниям операций
├── FilterProducer/          # Фабрики фильтров и генераторов
├── Filters/
│   ├── headers/             # IFilter, FilterDescriptor и классы операций
│   └── sources/             # Реализации фильтров и генераторов
├── Pipeline/                # Последовательное применение операций
└── readAndWrite/
    ├── headers/             # Waveform, структуры WAV и интерфейсы ввода/вывода
    └── sources/             # Хранение отсчётов, чтение и запись WAV
```

Чтобы добавить операцию, реализуйте интерфейс `IFilter`, добавьте фабрику в `FilterProducers`, зарегистрируйте её имя в `Application::configure()` и включите новые файлы в `CMakeLists.txt`.
